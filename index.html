About me

I'm Amgad, a final-year IT student at Northern Virginia Community College (NOVA). I'm focused on two areas that excite me the most: web design and cloud computing. On the web side, I enjoy writing clean, well-structured HTML and CSS and building pages that look good and work smoothly on any screen size, from phones to large desktops. I like the problem-solving part of front-end work — figuring out why a layout breaks, learning a new CSS technique, and seeing an idea turn into a real, working page. My goal is to grow into a web developer who can both design and code, so I can take a project from a rough concept all the way to a finished, responsive site. I treat this portfolio as a living project: I keep learning, and I add each new build to it as I go.
